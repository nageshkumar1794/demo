How does HashMap work internally?

HashMap uses a hash table to store key-value pairs. When a key-value pair is added, the key is hashed to produce an index in an array where the value will be stored. If two keys hash to the same index (a collision), HashMap uses a linked list or a balanced tree to store multiple entries at that index. When retrieving a value, the key is hashed again to find the correct index, and then the linked list or tree is searched for the specific. Uses an array of buckets. Each bucket stores a linked list or tree (since Java 8). Hashing: hash(key) determines bucket index. Collisions resolved using separate chaining (list/tree).
